# てん と せん — グラフ・ネットワーク理論 学習サイト

関西学院大学「グラフ・ネットワーク理論」（古谷倫貴 先生）の講義プリントをもとに、サカイ先輩とリョウガくんの対話・さわれるラボ・キネティックタイポグラフィで直感的に学ぶサイト。

## 収録
- 第1回 ガイダンス・グラフの定義・次数（ラボ6＋演習解答：ペテルセングラフの同型写像）
- 第2回 部分グラフ・補グラフ・特徴的なグラフ（ラボ6＋演習解答：δ(H) ≥ d(G)/2 の部分グラフ）
- 第3回 連結性・距離・木（ラボ7＋演習解答：定理3.2の証明）
- 第4回 連結度（切断点・頂点切断・κ(G)・ブロック木・耳分解。ラボ4＋演習解答：κ(Cₙ)=2, κ(Wₙ)=3, κ(K_{m,n})=min(m,n)）
- 第5回 Menger の定理（局所連結度・x-y 頂点切断・内素な道・縮約・Menger/Whitney。ラボ4＋演習解答：p.10 のグラフで κ_G(x,y)=3）
- 第6回 オイラー周遊（多重グラフ・ケーニヒスベルク・小径・定理6.1/系6.1.1・Hierholzer。ラボ5＋演習解答：p.21 の図形は奇点 b, e → b から e への一筆書き）
- 第7回 ハミルトン閉路（ハミルトン道／閉路・定理7.1 c(G−S)≤|S|・系7.1.1/7.1.2・Dirac 7.2・Ore 7.3・Bondy–Chvátal 閉包 7.4・2部グラフ 7.5／系7.5.1・TSP 7.6。ラボ5＋演習解答：G₃,₄ はハミルトングラフ、G₃,₃ は 2部彩色 5 対 4 より非ハミルトン）

## Vercel へのデプロイ
- リポジトリをそのまま Vercel にインポートするだけで動きます（`vercel.json` 同梱）。
- Framework Preset：**Other**（自動検出のままで OK）／ Root Directory：リポジトリ直下
- Build：`node scripts/build-static.mjs` → 出力 `out/`（依存パッケージのインストール不要・Node 18+）
- `/lec/*`, `/map`, `/words` は `index.html` にリライト（クライアント側ルーター）。
- Cloudflare Pages 版（Hono）は従来どおり `npm run build` → `dist/`。HTML の中身は `src/shell.js` を共有。
